## 作業評分（每份 10 分）

- repo 可存取、本人 commit 紀錄完整：1 分
- 程式可編譯執行、輸出符合規格（WAV 可播放）：4 分
- README 報告：推導/原理說明、圖表、結果分析：4 分
- 程式碼品質與註解：1 分
- 遲交每日扣 10%，最多 3 日。
