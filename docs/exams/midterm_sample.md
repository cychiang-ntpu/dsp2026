## 第 1 題　脈衝分解與卷積（8 分）

設 $`a=0.5`$，輸入 $`x[n]=\delta[n]+2\delta[n-1]-\delta[n-2]`$。

1. （2 分）直接用差分方程遞迴，計算 $`y[0]`$、$`y[1]`$、$`y[2]`$。
2. （3 分）求此系統的脈衝響應 $`h[n]`$，並以卷積和 $`y[n]=\sum_k x[k]\,h[n-k]`$ 重新計算 $`y[0]`$、$`y[1]`$、$`y[2]`$，驗證與第 1 小題相同。
3. （3 分）寫出 $`n\ge 2`$ 時 $`y[n]`$ 的一般式。

## 第 2 題　取樣與離散頻率（8 分）

連續時間訊號 $`x(t)=\cos(2\pi\cdot 3000\,t)`$ 以取樣率 $`f_s`$ 取樣，得 $`x[n]=x(n/f_s)`$。

1. （3 分）$`f_s=8000`$ Hz 時，求數位角頻率 $`\omega`$；$`x[n]`$ 是否為週期序列？若是，求最小週期 $`N`$。
2. （3 分）$`f_s=4000`$ Hz 時，回答同樣的問題，並將 $`\omega`$ 化到 $`(-\pi,\pi]`$ 區間內。
3. （2 分）第 2 小題的 $`x[n]`$ 與哪一個頻率（Hz）的弦波以 4000 Hz 取樣所得的序列完全相同？說明這個現象對 HW1 B5–B6 的分析有什麼影響。

## 第 3 題　以 z 轉換分析 RC 濾波器（17 分）

1. （3 分）對差分方程兩邊取 z 轉換，求系統函數 $`H(z)=Y(z)/X(z)`$。
2. （3 分）取 $`a=0.761`$，畫出 pole-zero plot（標出單位圓、極點與零點的位置）。此系統是 FIR 還是 IIR？為什麼？
3. （4 分）由 $`H(z)`$ 求脈衝響應 $`h[n]`$，並與第 1 題的結果比對。
4. （4 分）令 $`z=e^{j\omega}`$，寫出 $`\lvert H(e^{j\omega})\rvert`$ 與 $`\angle H(e^{j\omega})`$。利用 pole-zero plot 上「零點到 $`e^{j\omega}`$」與「極點到 $`e^{j\omega}`$」的向量，說明 $`\omega=0`$ 與 $`\omega=\pi`$ 時的增益各為多少，並說明為何這是低通濾波器。
5. （3 分）取樣率 $`f_s=8000`$ Hz、$`a=0.761`$，計算輸入頻率 400 Hz 時的 $`\lvert H\rvert`$ 與 $`\angle H`$（以 radian 表示），並與連續時間 RC 電路在截止頻率的結果（$`\lvert H\rvert=0.707`$、$`\angle H=-\pi/4`$）比較。

## 第 4 題　弦波輸入的輸出（8 分）

取樣率 $`f_s=8000`$ Hz、$`a=0.761`$，輸入對所有 $`n`$（$`-\infty<n<\infty`$）定義為

```math
x[n] = 2\cos\!\left(2\pi\frac{100}{8000}n\right) + \cos\!\left(2\pi\frac{3000}{8000}n\right)
```

已知：

| 頻率 | $`\lvert H\rvert`$ | $`\angle H`$（rad） |
|---|---|---|
| 100 Hz | 0.961 | $`-0.243`$ |
| 3000 Hz | 0.147 | $`-0.337`$ |

1. （5 分）利用 $`e^{j\omega n}`$ 是 LTI 系統的 eigenfunction，求輸出 $`y[n]`$。
2. （3 分）以第 3 題第 4 小題的相位公式，驗算 3000 Hz 的相位 $`-0.337`$ rad（寫出計算過程）。

## 第 5 題　moving average FIR 與 RC 低通比較（17 分）

把 HW1 `RC_filtering.c` 中的濾波器換成 4 點 moving average：

```math
y[n] = \frac{1}{4}\sum_{k=0}^{3} x[n-k]
```

1. （3 分）求 $`h[n]`$，並證明 $`H(z)=\dfrac{1}{4}\cdot\dfrac{1-z^{-4}}{1-z^{-1}}`$。
2. （4 分）畫出 pole-zero plot。$`z=1`$ 處發生什麼事？雖然 $`H(z)`$ 寫成分式，為什麼此系統仍是 FIR？
3. （5 分）導出 $`H(e^{j\omega})=e^{-j1.5\omega}\,\dfrac{\sin(2\omega)}{4\sin(\omega/2)}`$，並計算 $`\omega=0,\ \pi/4,\ \pi/2`$ 時的 $`\lvert H\rvert`$；與第 3 題 RC 濾波器（$`a=0.761`$）在相同頻率的 $`\lvert H\rvert`$ 比較。
4. （5 分）
   - 畫出 moving average 濾波器的 block diagram（使用延遲單元 $`z^{-1}`$、加法器、乘法器）。
   - 依 $`h[n]`$ 是否對稱，判斷 moving average 與 RC 濾波器何者為線性相位。
   - 比較兩者每個輸出樣本所需的乘法次數。

## 第 6 題　RC 低通串接一階差分（12 分）

將 RC 低通濾波器的輸出 $`y[n]`$ 再送進一階差分 $`w[n]=y[n]-y[n-1]`$。

1. （2 分）求整體系統函數 $`H(z)=W(z)/X(z)`$。
2. （3 分）畫出 pole-zero plot，判斷整體系統是 FIR 還是 IIR。
3. （4 分）由 $`H(z)`$ 求整體脈衝響應 $`h[n]`$，分別寫出 $`h[0]`$ 與 $`n\ge1`$ 時的 $`h[n]`$。
4. （3 分）求 $`\omega=0`$ 與 $`\omega=\pi`$ 的增益（$`a=0.761`$），並說明這是什麼類型的濾波器。

## 第 7 題　C 程式（12 分）

1. （6 分）寫出 C 函式，實作第 6 題的整體系統，必須符合 initial rest，且不得存取 `x[-1]`、`y[-1]` 等陣列範圍外的元素：

   ```c
   void rc_hp(const double *x, double *w, int N, double a);
   ```

2. （4 分）下列程式片段要實作 HW1 式 (8)，其中有兩個錯誤。請指出並改正。

   ```c
   int fs = 8000;
   double RC = 1.0 / (2 * M_PI * 400);
   double tau = 1 / fs;
   double a = RC / (RC + tau);

   for (int n = 0; n < N; n++) {
       y[n] = a * y[n - 1] + (1 - a) * x[n];
   }
   ```

3. （2 分）對長度 $`N`$ 的輸入，第 5 題的 moving average（直接依定義計算）與第 6 題的系統，總共各需要多少次乘法？

## 第 8 題　二階 IIR：複數極點與零點（18 分）

響度量測標準（ITU-R BS.1770 的 K-weighting）用二階 IIR 濾波器（biquad）調整各頻帶的權重。下面是一個簡化的同類濾波器，取樣率 $`f_s=48000`$ Hz，initial rest：

```math
y[n] = x[n] + 0.25\,x[n-2] - 0.81\,y[n-2]
```

1. （2 分）求系統函數 $`H(z)`$。
2. （4 分）求兩個零點與兩個極點，以極座標 $`re^{\pm j\theta}`$ 表示，並畫出 pole-zero plot（標出單位圓）。此系統是否穩定？是 FIR 還是 IIR？
3. （2 分）用遞迴計算脈衝響應 $`h[0]`$ 到 $`h[4]`$。
4. （5 分）計算 $`\omega=0,\ \pi/4,\ \pi/2,\ 3\pi/4,\ \pi`$ 時的 $`\lvert H(e^{j\omega})\rvert`$ 與 $`\angle H(e^{j\omega})`$（rad），畫出 $`0\le\omega\le\pi`$ 的振幅響應與相位響應草圖。利用 pole-zero plot 上的向量說明：振幅響應的峰值為何出現在 $`\omega=\pi/2`$？此濾波器加強了哪一個頻率（Hz）附近的訊號？
5. （5 分）下列輸入皆對所有 $`n`$（$`-\infty<n<\infty`$）定義，分別寫出輸出 $`y[n]`$：
   - $`x_1[n]=1`$
   - $`x_2[n]=\cos(\pi n/2)`$
   - $`x_3[n]=\cos(\pi n/4+\pi/6)`$
   - $`x_4[n]=(-1)^n`$
   - $`x_5[n]=x_1[n]+x_3[n]`$

   並說明 $`x_2`$ 與 $`x_3`$ 各對應多少 Hz 的類比訊號。
